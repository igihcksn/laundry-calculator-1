# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam kilogram dan langsung mengetahui apabila aturan berat minimal 3 kg diberlakukan.

## Alur
1. Pengguna mengisi estimasi berat pada kolom angka (mendukung tanda koma `,` maupun titik `.`) atau menekan tombol penyesuaian cepat `- 0,5 kg` dan `+ 0,5 kg`.
2. Sistem menghitung `beratDitagih = Math.max(3, beratAktual)` setiap kali nilai berat berubah.
3. Jika berat aktual valid (`> 0`) dan kurang dari `3 kg`, muncul notifikasi visual berwarna amber bahwa ketentuan minimum charge 3 kg diberlakukan.
4. Jika berat kosong atau `<= 0`, perhitungan biaya diset ke Rp 0 dan saat submit sistem menampilkan pesan error pada kolom berat.

## Data
- `STORE_INFO.minimumChargeKg` (`3.0`) dan `WEIGHT_LIMITS` (`min: 0.1`, `max: 200`, `step: 0.5`) dari `src/config.ts`.

## Aturan dan rumus
- Satuan berat: kilogram (`kg`), resolusi input `0,1` kg.
- Parsing input menerima koma maupun titik sebagai pemisah desimal.
- Berat ditagih:
  - Jika `beratAktual > 0`: `beratDitagih = Math.max(3.0, beratAktual)`
  - Jika input kosong, bukan angka, atau `<= 0`: berat tidak valid untuk pengiriman pesanan (`beratDitagih = 0`).
- Flag `apakahMinimumCharge`: bernilai `true` apabila `beratAktual > 0 && beratAktual < 3.0`.

## Input dan validasi
- Kolom `estimasiBerat`: wajib diisi, angka `>= 0,1` dan `<= 200`.
- Pesan error jika kosong atau `<= 0`: "Masukkan estimasi berat cucian lebih dari 0 kg, contoh: 2,5".
- Pesan error jika `> 200`: "Estimasi berat maksimal 200 kg per pesanan, contoh: 12".
- Validasi diperiksa saat tombol "Kirim ke WhatsApp" ditekan, dan fokus pindah ke kolom berat jika kolom ini yang bermasalah pertama.

## Tampilan dan teks
- Judul bagian: "Estimasi Berat Cucian".
- Label selalu terlihat: "Berat cucian (kg)" dengan satuan "kg" di sisi kanan input dan tombol cepat `-` / `+` berarea sentuh minimal 44 x 44 px.
- Notifikasi minimum charge (tampil saat `0 < beratAktual < 3`): kotak `bg-amber-50 text-amber-800` dengan ikon informasi dan teks "Berat di bawah 3 kg dikenakan tarif minimal 3 kg." serta penegasan "Berat ditagih: 3 kg".
