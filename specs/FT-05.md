# FT-05 Form Data Pemesan

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-05), Bagian 8 (AC-03), Bagian 9 (TC-04)

## Tujuan
Pengguna dapat mengisi nama, alamat penjemputan (bila Antar-Jemput aktif), dan catatan khusus cucian sebelum mengirim pesanan.

## Alur
1. Pengguna mengisi kolom Nama Lengkap (wajib).
2. Jika add-on Antar-Jemput dicentang, kolom Alamat Penjemputan muncul otomatis dan wajib diisi; jika tidak dicentang, tampil keterangan bahwa cucian diantar sendiri ke toko.
3. Pengguna dapat mengisi Catatan Khusus secara opsional (misalnya pemisahan bahan atau jam jemput).
4. Saat tombol kirim ditekan, spasi awal dan akhir dipangkas lalu seluruh aturan validasi diperiksa.

## Data
- `STORE_INFO.pickupRadiusMaxKm` (`5`) dari `src/config.ts`.

## Aturan dan rumus
- Pembersihan teks: `trim()` dilakukan pada nama, alamat, dan catatan sebelum validasi dan pembentukan pesan WhatsApp.
- Jika `antarJemputAktif` bernilai `false`, isi pesan alamat otomatis memakai `"Antar Sendiri ke Toko"` sesuai template PRD.
- Jika `catatan` kosong setelah `trim()`, isi pesan catatan otomatis memakai `"-"` sesuai template PRD.

## Input dan validasi
- `namaPelanggan`: wajib diisi, tidak boleh kosong setelah `trim()`.
  - Error: "Masukkan nama Anda agar pesanan mudah dicatat, contoh: Budi Santoso".
- `alamatJemput`: wajib diisi hanya jika `antarJemputAktif === true`.
  - Error: "Masukkan alamat penjemputan lengkap, contoh: Jl. Melati No. 12, Kost Putri".
- `catatanKhusus`: opsional, menerima teks bebas termasuk tanda baca (`&`, `!`, `,`).
- Atribut aksesibilitas: `name`, `autocomplete="name"` untuk nama, `autocomplete="street-address"` untuk alamat, label selalu terlihat, ukuran font input minimal 16 px.

## Tampilan dan teks
- Judul bagian: "Data Pemesan".
- Kolom Nama: label "Nama pemesan", placeholder "Contoh: Budi Santoso".
- Kolom Alamat (muncul jika Antar-Jemput aktif): label "Alamat penjemputan", teks bantuan "Area penjemputan maksimal radius 5 km.", placeholder "Contoh: Jl. Melati No. 12, RT 02".
- Jika Antar-Jemput tidak aktif, tampil teks pendukung singkat: "Pakaian akan Anda antar sendiri ke toko."
- Kolom Catatan: label "Catatan khusus (opsional)", placeholder "Contoh: Pisahkan pakaian putih".
